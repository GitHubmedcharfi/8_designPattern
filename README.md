# 8 Design Patterns in Java

A collection of 8 Design Patterns implemented in Java through practical real-world software engineering use cases.

## Behavioral Patterns

| Pattern      | Real-World Use Case          |
| ------------ | ---------------------------- |
| **Observer** | Real-Time Chat Notifications |
| **Strategy** | Flexible Payment System      |

## Creational Patterns

| Pattern              | Real-World Use Case            |
| -------------------- | ------------------------------ |
| **Abstract Factory** | Multi-Target Logging System    |
| **Factory Method**   | Real-Time Notification System  |
| **Singleton**        | Database Connection Management |

## Structural Patterns

| Pattern       | Real-World Use Case              |
| ------------- | -------------------------------- |
| **Composite** | Company Organizational Structure |
| **Decorator** | Secure File Storage System       |
| **Proxy**     | Cost-Efficient AI Service        |
